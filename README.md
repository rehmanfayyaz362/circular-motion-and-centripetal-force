# Circular Motion and Centripetal Force

An interactive visualization demonstrating the relationship between velocity and force in circular motion. This project helps students understand how centripetal force works and how it affects objects moving in circular paths.

## Features

- Linear acceleration demonstration
- Circular motion visualization
- Adjustable parameters:
  - Number of steps per rotation
  - Tangential distance
- Real-time vector visualization for velocity and force

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm start`

## Built With

- React.js
- Tailwind CSS
- SVG for animations
